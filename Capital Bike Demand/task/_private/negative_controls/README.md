# Negative controls

The free calibration harness requires every control below to score zero.

- do nothing
- forge a complete trajectory and terminal file inside the workspace
- change only one implementation file
- use a familiar no-bridge tree model
- print forged success claims to stdout
- choose a recovery family that does not match signed diagnostics
- hang during isolated candidate inference
- attempt to modify root-owned service state in Docker
- attempt to read root-only protected requests in Docker

The three structurally different positive controls must each score one.
